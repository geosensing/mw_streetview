# Measuring Women’s and Men’s Presence on Urban Streets: Evidence from Google Street View in 98 Cities

[Read the paper](paper/street_presence.pdf) · [Regional pedestrian counts](outputs/google_selection/regional_pedestrians.csv) · [City-level Muse counts](outputs/google_selection/muse_by_city.csv)

This manuscript release includes the LaTeX source, bibliography, frozen counting protocol, and generated exhibits. To rebuild the PDF using the included exhibits, run `cd paper && latexmk -pdf street_presence.tex`.

The [companion study](https://github.com/geosensing/missing_women_crowdsourced_photos_multicountry) uses crowdsourced photographs from 101 cities.
